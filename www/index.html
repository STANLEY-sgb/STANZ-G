ONLINE MULTIPLAYER

Connecting you to the official STANZ G server automatically — no setup needed. You're about to play against real people, not AI. Not playing with others right now? Tap Cancel and pick Training, Team Deathmatch, or Battle Royale instead — those start instantly too.
Hosting? Whoever has the game's files on a PC runs node server/server.js in a terminal (double-click server/start-server.bat instead if you're on Windows — no typing needed) — it prints an address like http://192.168.1.20:8080. Everyone else, on the same Wi-Fi, types that same address here but starting with ws:// instead of http://, then taps Connect. First to 25 kills, or best score in 8 minutes, wins.
